# images 폴더

사이트에서 사용하는 이미지와 아이콘을 모아 둔 폴더입니다.

## 파일 목록

| 파일 | 용도 | 크기 | 출처·라이선스 |
| --- | --- | --- | --- |
| `favicon.svg` | 브라우저 탭 아이콘 (터미널 프롬프트 `>_` 모양) | 64x64 viewBox | 팀에서 직접 제작 (외부 자료 없음) |

## 규칙

- 파일명은 소문자와 하이픈만 사용합니다. (예: `team-photo.png`)
- 새 이미지를 추가하면 위 표에 용도와 출처·라이선스를 함께 적습니다.
- 외부 이미지는 사용 허가가 확인된 것만 쓰고, 출처를 표에 남깁니다.
- 모든 `<img>`에는 `alt` 속성을 넣습니다. 장식용이면 `alt=""`로 둡니다.
- 개인정보(얼굴 사진, 연락처 등)가 담긴 이미지는 올리지 않습니다.

프로젝트 소개

이 사이트는 Git과 GitHub로 협업하며 HTML, CSS, JavaScript만으로 만든 정적 웹사이트입니다. 기능마다 Issue를 만들고, 브랜치에서 개발한 뒤 Pull Request와 코드 리뷰를 거쳐 병합했습니다.

  • Issue

    기능마다 담당자와 완료 조건을 정리해 작업을 관리합니다.

  • Branch & PR

    기능 브랜치에서 개발하고 Pull Request로 변경 내용을 공유합니다.

  • Review

    팀원의 코드를 서로 검토하고 개선 의견을 남깁니다.

주요 메뉴

  • $ cd about 팀 소개 팀의 목표와 구성 배경, 활동 방향
  • $ cd members 팀원 프로필 6명의 관심 분야와 기술, 학습 목표
  • $ cd projects 프로젝트 갤러리 팀과 개인 프로젝트 결과물
  • $ cd activities 활동 기록 회의와 개발 과정을 담은 개발 일지
  • $ cd faq FAQ 자주 묻는 질문과 답변

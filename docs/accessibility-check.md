| 페이지 | 확인 범위 | 결과 |
| --- | --- | --- |

## 코드 점검

- 네 페이지 모두 한국어 언어 설정, 고유한 title, h1 하나와 main이 있음. 정적 HTML의 중복 id 없음.
- 현재 루트 HTML에는 img 요소가 없어 alt 점검은 해당 없음. 이미지 추가 시 재점검 필요.
- 홈의 터미널 예시는 role="img"와 aria-label로 설명하고 내부 장식은 aria-hidden 처리함. 갤러리 장식 썸네일도 aria-hidden 처리함.
- 검색창의 label, 필터 button과 aria-pressed, 결과 개수의 role="status" 및 aria-live가 있음.
- 공통 CSS에 focus-visible 표시, hidden 처리, 움직임 줄이기 설정이 있음.
- 모바일 메뉴에 aria-expanded·aria-controls와 Esc 닫기 처리가 있음.
- 색 대비 측정과 실제 스크린리더 검증은 수행하지 않음. 전체 접근성 표준 준수를 보장하는 검사는 아님.

## 소규모 개선

### 404 본문 바로가기 — js/common.js

기존 href="#main"은 404의 base를 기준으로 해석되어 사이트 루트로 이동할 수 있습니다. 헤더 생성 후 링크를 현재 문서 전체 주소 + #main으로 설정했습니다. 쿼리는 유지하고 기존 해시는 교체합니다. base와 복귀 버튼, 디자인은 유지합니다.

### 필터 초기화 후 초점 — js/filter.js

초기화 버튼을 누르면 해당 버튼이 숨겨집니다. 키보드 사용을 이어갈 수 있도록 결과 초기화 후 검색창의 focus()를 호출했습니다. 검색 조건과 카드 구성은 유지합니다.

## 수정 후 코드 검증

수정한 코드에 대해 다음 검사를 수행했습니다. 코드 검사와 실제 브라우저 조작 결과를 구분하여 기록합니다.

- 두 JS 파일의 node --check 및 git diff --check 통과.
- Node 모의 DOM 테스트에서 이전 코드의 문제 조건을 확인하고 수정 후 통과함.
  - 일반 페이지, 직접 404 주소, 깊은 오류 주소(쿼리·해시 포함), 로컬 파일 주소에서 본문 바로가기 URL 확인.
  - 검색 결과 없음 → 초기화 시 검색어 삭제·전체 결과 복구·초기화 버튼 숨김·검색창 초점 이동 확인.
- 모의 DOM 검증은 브라우저 화면·키보드·보조기술 검증을 대체하지 않음.

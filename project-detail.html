D = Dev Log · 여섯 명의 개발 과정과 협업을 기록하는 팀 프로젝트

프로젝트 목적

팀원들의 소개와 프로젝트 결과물, 활동 기록을 하나의 웹사이트에 모읍니다. HTML, CSS, JavaScript로 웹페이지를 만들고 Git과 GitHub를 활용한 협업 과정을 경험하는 것이 목표입니다.

사용 기술

  • HTML: 제목, 본문, 링크 등 페이지의 구조를 만듭니다.
  • CSS: 색상, 글꼴, 배치와 화면 크기에 따른 모양을 정합니다.
  • JavaScript: 모바일 메뉴와 프로젝트 검색·필터 동작을 처리합니다.
  • Git · GitHub: 변경 이력을 관리하고 코드 리뷰로 작업을 합칩니다.
  • GitHub Pages: 정적 웹사이트를 배포합니다. 별도의 서버 프로그램이나 데이터베이스는 사용하지 않습니다.

주요 기능과 개발 계획

  • 메인 페이지에서 팀의 콘셉트와 주요 메뉴를 소개합니다.
  • 프로젝트 갤러리에서 결과물을 모아 보고 검색과 분류 필터로 찾습니다.
  • 상세 페이지에서 프로젝트의 목적, 기술, 기능, 참여자를 확인합니다.
  • 공통 메뉴와 반응형 배치로 PC와 모바일 화면을 지원합니다.
  • 팀 소개, 팀원 프로필, 활동 기록, FAQ 페이지는 팀원들이 나누어 개발합니다.
